# AI档案室 产品介绍

AI档案室是一个基于私有知识库的 AI 问答小程序，由 Tom 于 2026 年 8 月启动开发。

## 核心功能
1. 文档管理：用户可上传 txt、md、pdf、docx 格式的文档，单文件最大 20MB，单个用户总容量 100MB，最多 10 个文档。
2. AI 问答：基于用户上传的文档进行流式回答，回答必须带引用溯源，只基于文档内容回答，禁止编造。
3. 免费额度：免费用户每天可进行 20 轮问答，看激励视频可以解锁额外额度。
4. 混合检索：采用 BM25 关键词检索 + 向量检索 + MMR 重排的混合检索策略。

## 技术架构
- 前端：微信原生小程序
- 后端：FastAPI + PostgreSQL + pgvector
- 嵌入模型：BGE-M3（1024 维）
- LLM：DeepSeek API
- 部署：腾讯云轻量服务器 + Docker

## 版本规划
- M1：MVP 自用版本，支持文档上传与 AI 问答
- M2：多租户用户系统
- M3：额度与广告系统
- M4：正式上架微信小程序
