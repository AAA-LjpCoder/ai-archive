# 检索质量评测报告

> 项目最硬的指标在这儿：**最终检索管线 R@6 = 91.2%**。
> 快照日期：2026-08-14（检索升级「V2.0 极致版」时，提交 `d382800`）。

## 结论

在自建的 **34 题 golden set** 上，最终管线（**v2 全库混合检索 + 精排** × **新解析器数据**）：

| 指标 | 结果 |
|---|---|
| **Recall@6** | **91.2%** |
| Recall@3 | 88.2% |
| Recall@1 | 79.4% |
| **MRR** | **0.844** |
| 关键词覆盖 | 95.4% |

## 方法

- **golden set**：34 条（`eval/golden_qa.json`），覆盖单点事实 / 多文档综合 / 列表枚举 / 否定性等题型；每条标注 `keywords`（答案应覆盖的关键词）。
- **指标**：
  - `Recall@K` —— 正确答案所在片段是否落在 top-K；
  - `MRR` —— 首个相关片段的平均倒数排名；
  - 关键词覆盖率 —— top-K 内累加命中的关键词占比。
- **对照脚本**：`backend/scripts/eval_retrieval.py`（`--pipeline baseline|v2`、`--rerank`）。
- **语料**：`eval/documents/`（4 份真实文档）。

### 两个自变量

1. **检索管线**：`v1`（向量 + 池内 BM25 + MMR） vs `v2`（全库 BM25 + 大候选池 60∪60 + RRF + **精排**）。
2. **数据**：旧解析器产物 vs 新解析器重建（结构感知分块）。

## 结果（34 题）

| 指标 | v1 · 旧数据 | v2 · 旧数据 | v1 · 新数据 | **v2 · 新数据** |
|------|:---:|:---:|:---:|:---:|
| Recall@1 | 29.4% | 41.2% | 73.5% | **79.4%** |
| Recall@3 | 35.3% | 58.8% | 79.4% | **88.2%** |
| Recall@6 | 50.0% | 64.7% | 82.4% | **91.2%** |
| MRR | 0.348 | 0.501 | 0.765 | **0.844** |
| 关键词覆盖 | 58.6% | 74.7% | 85.1% | **95.4%** |

**读法**：换「新解析器数据」提升最大（分块质量是召回的地基）；在此之上叠「v2 管线 + 精排」把 R@6 从 82.4% → 91.2%。
