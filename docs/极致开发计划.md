---

## 现状盘点（已完成）

- 后端：FastAPI + PG(pgvector) + BGE-M3 向量 + 池内 BM25 + RRF + MMR
  - ⚠️ BM25 只在向量 top20 候选池内计算（idf 不准、召回受限）
  - ⚠️ 无精排模型（MMR 只做多样性，相关性排序弱）
- 解析：txt / md / pdf / docx
  - ⚠️ PDF 无 OCR 兜底（扫描件直接失败）
  - ⚠️ 不支持 pptx / xlsx / epub / html / csv
- 前端：档案盒主题（墨绿 #146B5A + 米白 + 金棕），流式问答 + 引用 + Markdown 渲染
  - 功能完备，视觉有底子但缺"眼前一亮"的动效与质感
- 数据：服务器 4 份真实文档 / 147 chunks（评测素材 ✓）

## 已确认可用的能力

- 硅基流动 `BAAI/bge-reranker-v2-m3` rerank API ✅（实测 200）
- 硅基流动 Qwen-VL 可做图片/扫描件 OCR（key 同 embedding key）
- SSH 免密访问服务器（122.51.27.182）+ docker exec PG ✅

## Phase 1：检索质量（准确率 / 召回率）— 今天做

### 1.1 检索管线升级

| # | 改进 | 预期收益 |
|---|------|---------|
| 1 | BM25 全库独立检索（预计算词频统计表，jieba 分词落库） | 召回率↑（不再被向量 top20 限制） |
| 2 | 候选池扩大：向量 top60 ∪ BM25 top60 | 召回率↑ |
| 3 | **bge-reranker-v2-m3 精排**：RRF 融合后 top30 → 重排 → top6 | 准确率↑↑（相关性排序质变） |
| 4 | 动态片段数：按问题长度/文档数自适应 rerank_n | 答案质量↑ |
| 5 | 引用片段携带 heading 上下文 | 溯源体验↑ |

### 1.2 评测体系（可量化）

- 从真实文档构建 **golden QA 集**（≥30 条，含：单点事实 / 多文档综合 / 列表枚举 / 否定性）
- 指标：**Recall@K**（正确答案所在片段是否在 topK）、**MRR**、**命中文档数**
- 脚本：`backend/scripts/eval_retrieval.py` —— baseline vs 新版管线对比报告
- 目标：Recall@6 ≥ 85%（现网待测）

## Phase 2：文档解析全面化

| 格式 | 方案 |
|------|------|
| pptx | python-pptx：逐页提取文本框/表格/备注 |
| xlsx | openpyxl：多 sheet、合并单元格、公式值 |
| epub | 解压 zip → 解析 XHTML（复用 md 结构逻辑） |
| html | BeautifulSoup / lxml → 标题层级 + 正文 + 表格 |
| csv | 按行转表格块 |
| **PDF 扫描件** | pdfplumber 提取为空 → 自动触发 OCR 兜底（硅基流动 Qwen-VL，逐页） |
| 图片 | 文档内嵌图片 OCR（Qwen-VL） |

- 解析测试集：每种格式 ≥2 个样例，`tests/test_parser.py` 扩充
- 乱码/加密检测：字符密度 + pdf 加密异常捕获

## Phase 3：UI 眼前一亮

1. **首页（档案柜）**：卡片质感升级（纸张纹理、档案袋标签、状态动效）、解析进度动画、骨架屏
2. **聊天页**：消息渐入动画、打字光标、引用徽章化、回答卡片化、Markdown 渲染增强（代码高亮、表格、引用块、列表）
3. **微交互**：答案点赞/点踩（收集 bad case → 反哺评测集）、复制、重新生成
4. **欢迎页/空状态**：纯 CSS 品牌插画 + 引导
5. 全局：毛玻璃导航、页面切换过渡、深浅色模式
